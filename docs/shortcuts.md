# Keyboard shortcuts

The shortcuts are also shown next to each item in the menus.

## File

| Shortcut | Action |
| --- | --- |
| Ctrl+N | New repository… |
| Ctrl+O | Add local repository… |
| Ctrl+Shift+O | Clone repository… |
| Ctrl+, | Options… |

## View

| Shortcut | Action |
| --- | --- |
| Ctrl+1 | Changes |
| Ctrl+2 | History |
| Ctrl+3 | Full-width diff (toggle) |
| Ctrl+T | Repository list |
| Ctrl+B | Branches list |
| F5 | Refresh |

In the repository and branch lists, type to filter, Enter opens the first match, and Esc closes the list.

## Repository

| Shortcut | Action |
| --- | --- |
| Ctrl+P | Push |
| Ctrl+Shift+P | Pull |
| Ctrl+Shift+T | Fetch |
| Ctrl+Shift+G | View on GitLab / GitHub |
| Ctrl+Shift+F | Show in Explorer / Finder |
| Ctrl+Shift+A | Open in editor |
| Ctrl+I | Create issue |

## Branch

| Shortcut | Action |
| --- | --- |
| Ctrl+Shift+N | New branch… |
| Ctrl+Shift+R | Rename… |
| Ctrl+Shift+D | Delete… |
| Ctrl+Shift+S | Stash all changes |
| Ctrl+Shift+U | Update from the default branch |
| Ctrl+Shift+B | Compare to branch |
| Ctrl+Shift+M | Merge into current branch… |
| Ctrl+Shift+H | Squash and merge into current branch… |
| Ctrl+Shift+E | Rebase current branch… |
| Ctrl+Shift+C | Compare on GitLab / GitHub |
| Ctrl+Alt+B | View branch on GitLab / GitHub |
| Ctrl+Alt+P | Create merge request / pull request |
| Ctrl+R | View merge request / pull request |
